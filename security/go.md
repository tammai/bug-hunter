# Security checklist: Go backends (net/http, Gin, Echo, Fiber)

Use with the generic and PII checklists.

## Injection and code execution
- **SQL built with formatting:** `db.Query(fmt.Sprintf("... WHERE id = %s", id))`, string `+` or `strings.Builder` queries passed to `db.Query`, `QueryRow`, `Exec`, `sqlx.Get`, `gorm.Raw`, `db.Where("name = '" + name + "'")`. Placeholders (`$1`, `?`) and `Where("name = ?", name)` are safe; column names and `ORDER BY` pieces from input are not covered by placeholders. CWE-89.
- **`os/exec` with input:** `exec.Command("sh", "-c", ...)` or `bash -c` with request data, or `exec.Command(userValue, ...)`. Even without a shell, an argument that starts with `-` can be read as an option by the program. CWE-78.
- **Template choice:** `text/template` used to render HTML, or `html/template` defeated with `template.HTML(userInput)`, `template.JS`, `template.URL`, or `template.HTMLAttr`. Also `fmt.Fprintf(w, ...)` or `w.Write` of input into an HTML response with a `text/html` content type. CWE-79.
- **Path traversal:** `filepath.Join(baseDir, r.URL.Query().Get("file"))`, `os.Open`, `http.ServeFile`, or `ioutil.ReadFile` on a joined path. `filepath.Join` and `filepath.Clean` don't stop `..` from escaping the base: `Clean("/../x")` just normalizes. Check the result with `filepath.Rel` or `strings.HasPrefix` on the cleaned absolute path, or use `os.Root` / `http.Dir` with care. `http.FileServer(http.Dir("."))` can serve source files and `.env`. CWE-22.
- **Archive extraction:** `archive/zip` or `archive/tar` entries written to `filepath.Join(dest, header.Name)` with no check for `..` (zip slip). CWE-22.
- **Unsafe code and reflection:** the `unsafe` package, `reflect` driven by input field names, `plugin.Open`, or `text/template` parsing a template string from the user. CWE-94, CWE-119.
- **Decoding:** `gob.Decode` or `encoding/json` into `interface{}` for control decisions, and `yaml.Unmarshal` into types from input, with no `DisallowUnknownFields` or limits (see mass assignment below). CWE-502.
- **SSRF and redirects:** `http.Get(r.FormValue("url"))`, `http.Redirect(w, r, r.URL.Query().Get("next"), ...)`, `c.Redirect(...)` with unchecked targets; `http.Client` following redirects to internal hosts. CWE-918, CWE-601.

## Authorization and authentication
- **Missing authz middleware:** a Gin `router.Group("/admin")` or Echo `e.Group` created without `.Use(authMiddleware)`, a route registered on the root router instead of the protected group, `mux.Handle` or `http.HandleFunc` handlers that never call the session check, or Gin middleware added with `Use` *after* the routes it should cover (Gin applies it only to routes registered after; Echo's root `e.Use` covers every route). CWE-862.
- **IDOR:** `c.Param("id")`, `chi.URLParam`, `r.PathValue("id")` or a JSON body id passed to `db.First(&obj, id)`, `FindByID`, `Delete` with no `AND user_id = ?` or ownership check. Check the service and repository layers. CWE-639.
- **Mass assignment:** `c.ShouldBindJSON(&user)`, `json.NewDecoder(r.Body).Decode(&user)` or `c.BodyParser(&user)` into a struct that also holds `Role`, `IsAdmin`, `OwnerID`, `Price` or `ID`, then saved with `db.Save` or `Updates`. Use a separate input struct, `DisallowUnknownFields`, and `json:"-"` on server-only fields. CWE-915.
- **JWT handling:** `jwt.Parse` or `ParseWithClaims` (golang-jwt/jwt) whose key function doesn't check `token.Method` (algorithm confusion, `none` accepted), `ParseUnverified` used for decisions, a hard-coded `[]byte("secret")` signing key, no `exp` claim validation, or claims read from a token that failed `err` checks. CWE-347, CWE-798.
- **Ignored errors on auth paths:** `claims, _ := parse(token)`, `ok, _ := checkPassword(...)`, `_ = verify(...)`, a `bcrypt.CompareHashAndPassword` result only logged, or `if err != nil { log... }` with no `return`, so execution continues as if authenticated. CWE-252, CWE-390.
- **Comparisons and tokens:** `==` or `bytes.Equal` on secrets, signatures or API keys instead of `subtle.ConstantTimeCompare` or `hmac.Equal`; passwords hashed with `md5`, `sha1` or `sha256` instead of bcrypt, scrypt or argon2. CWE-208, CWE-916.
- **Weak randomness:** `math/rand` (or `math/rand/v2`) for session ids, reset tokens, API keys, OTPs, or nonces, rather than `crypto/rand`. Seeding with `time.Now().UnixNano()` is guessable. CWE-338.
- **Sessions and cookies:** `http.Cookie` or `gorilla/sessions` with no `Secure`, `HttpOnly` or `SameSite`, a hard-coded `NewCookieStore([]byte("..."))` key, no CSRF middleware (`gorilla/csrf`, Echo's CSRF) on cookie-authenticated state changes. CWE-614, CWE-1004, CWE-352.

## Network, TLS and resources
- **`http.Client` without timeouts:** `http.Get`, `http.Post`, `http.DefaultClient` or `&http.Client{}` with no `Timeout`, and servers built with `http.ListenAndServe` or `&http.Server{}` with no `ReadHeaderTimeout`, `ReadTimeout`, `WriteTimeout`, `IdleTimeout` (slowloris). Unclosed `resp.Body`. CWE-400.
- **Unbounded bodies:** `io.ReadAll(r.Body)`, `ioutil.ReadAll`, `r.ParseMultipartForm(<huge>)` or JSON decoders with no `http.MaxBytesReader`. CWE-770.
- **TLS:** `tls.Config{InsecureSkipVerify: true}`, `MinVersion` unset or below TLS 1.2, custom `VerifyPeerCertificate` that returns nil, or `http.ListenAndServe` serving credentials over plain HTTP. CWE-295, CWE-319.
- **CORS:** `cors.Default()` or `AllowAllOrigins: true` with `AllowCredentials: true`, or an origin reflected from `r.Header.Get("Origin")`. CWE-942.
- **Data races on shared state:** a package-level `map[string]*Session`, a user cache or a rate limiter touched by several handlers (each request runs in its own goroutine) with no `sync.Mutex`, `sync.RWMutex` or `sync.Map`; shared loop variables captured by `go func()`; check-then-act on balances or stock. Concurrent map writes panic the server, and races on identity data mix users up. CWE-362.
- **Panics and recovery:** handlers that index slices, dereference pointers or type-assert (`x.(T)` without the comma-ok form) on request data; no `recover` middleware (`gin.Recovery()`, Echo `middleware.Recover()`) or no recover inside spawned goroutines. `net/http` recovers a panic in the handler goroutine itself, but a panic in a goroutine the handler starts with `go func()` kills the whole process. CWE-248, CWE-476.
- **Debug and error exposure:** `gin.SetMode(gin.DebugMode)` in production, `net/http/pprof` imported in the main server (the blank import registers `/debug/pprof` on the default mux), `expvar`, and `err.Error()` from the database returned to clients. CWE-489, CWE-209.
- **Logging:** `log.Printf("%+v", user)`, `c.Request.Header` dumps, and request-logging middleware that records `Authorization`, cookies or bodies. CWE-532.
