# Security checklist: PHP backends (Laravel, Symfony, plain PHP)

Use with the generic and PII checklists.

## Injection and code execution
- **SQL built by concatenation:** `mysqli_query($c, "... $_GET[id]")`, `$pdo->query("... " . $id)`, `$pdo->exec(...)`, `->prepare()` on a string that already holds input; Laravel `DB::raw`, `DB::select("... $x")`, `whereRaw`, `selectRaw`, `orderByRaw`, `havingRaw`, `groupByRaw` with variables; Symfony/Doctrine `createQuery("... $x")`, `$conn->executeQuery("... $x")`, `createNativeQuery`. Bindings (`?`, `:name`, `setParameter`) are safe; column names and `orderBy($request->sort)` are not. CWE-89.
- **`unserialize` on input:** `unserialize($_COOKIE[...])`, `unserialize($request->input(...))`, values from the database or cache a user can edit, `phar://` paths reaching file functions (`file_exists`, `is_file`, `getimagesize`). Magic methods (`__destruct`, `__wakeup`) become a gadget chain. Use `json_decode` or `allowed_classes => false`. CWE-502.
- **File inclusion:** `include`, `include_once`, `require`, `require_once` with a variable built from `$_GET`, `$_POST`, a route parameter or a header (`?page=`); Blade or Twig template names from input; `allow_url_include` on. CWE-98, CWE-22.
- **Dynamic code:** `eval(`, `assert($string)`, `create_function`, `preg_replace` with the `/e` modifier (old code), `call_user_func($_GET["fn"])`, `$$var` variable variables, `extract($_REQUEST)`, `parse_str` without a result array, `$obj->{$input}()`. CWE-94, CWE-95, CWE-621.
- **Command execution:** `exec`, `system`, `passthru`, `shell_exec`, backticks, `popen`, `proc_open`, `pcntl_exec`, `mail()` additional-parameters argument with input, `escapeshellarg` missing on each argument (and `escapeshellcmd` used as a substitute). CWE-78, CWE-88.
- **XSS:** `echo $_GET['q']`, `<?= $name ?>`, `print`, `printf` of input without `htmlspecialchars($s, ENT_QUOTES, 'UTF-8')` or `htmlentities`; Blade `{!! $var !!}` (the `{{ }}` form escapes); Twig `|raw` or `autoescape false`; `e()` skipped; Symfony `Response` returning HTML built with string concatenation. CWE-79.
- **Header and email injection:** `header("Location: " . $_GET['url'])` (open redirect and newline injection), `redirect($request->input('next'))`, `Redirect::to($url)`, `mail($to, $subject, $body, $headers)` with input in headers. CWE-601, CWE-113.
- **XML:** `simplexml_load_string`, `DOMDocument::loadXML` with `LIBXML_NOENT` or `LIBXML_DTDLOAD` on untrusted XML (XXE). CWE-611.

## Files and outbound requests
- **SSRF:** `file_get_contents($url)`, `fopen($url)`, `curl_init($url)`, `Http::get($request->url)`, Guzzle `$client->get($input)`, `simplexml_load_file`, `getimagesize($url)`, with a user URL, no allow-list, no private-range block, redirects followed (`CURLOPT_FOLLOWLOCATION`), `allow_url_fopen` on. Also `file_get_contents($_GET['file'])` reading local files. CWE-918, CWE-22.
- **Uploads:** `move_uploaded_file($_FILES['f']['tmp_name'], $dir . $_FILES['f']['name'])` using the client's name; checking `$_FILES['f']['type']` (client-sent) instead of content; extension checks that allow `.php`, `.phtml`, `.phar` or double extensions; the upload directory under the web root with PHP execution on; Laravel `$request->file()->store()` with `getClientOriginalName()` / `getClientOriginalExtension()` and no `mimes` or `max` validation rule. CWE-434, CWE-22.
- **Path traversal:** `readfile`, `file_get_contents`, `fopen`, `unlink`, `Storage::download($request->path)`, `response()->download($path)`, `BinaryFileResponse` with `$base . $input`; `realpath` result not compared with the base; `basename()` skipped. CWE-22.
- **Download and error output:** `display_errors=On`, `error_reporting(E_ALL)` and `phpinfo()` pages left in production, backups or `.sql`, `.env`, `.git` files under the web root, `composer.json`/`vendor/` reachable from the web. CWE-209, CWE-200, CWE-538.

## Authentication and authorization
- **Missing middleware or policy:** Laravel routes with no `->middleware('auth')` (or `auth:sanctum`, `auth:api`) while siblings have it, route groups defined outside the `Route::middleware(...)->group`, controllers whose methods never call `$this->authorize()`, `Gate::allows`, `$user->can()` or a `FormRequest::authorize()` that simply returns `true`; Symfony `access_control` rules ordered so a broad pattern matches first, `#[IsGranted]` or `denyAccessUnlessGranted` missing on a sibling action, `security.yaml` with `PUBLIC_ACCESS` on too much; plain PHP pages that forget `session_start()` plus a login check on one file. CWE-862, CWE-306.
- **IDOR:** `Order::find($id)`, `findOrFail($request->id)`, `$repository->find($id)`, `SELECT ... WHERE id = ?` with no `where('user_id', auth()->id())` or `$request->user()->orders()->findOrFail($id)` scoping or policy check. CWE-639.
- **Mass assignment:** Eloquent models with `protected $guarded = []` or `$fillable` that includes `role`, `is_admin`, `owner_id`, `balance`, then `Model::create($request->all())`, `->update($request->all())`, `->fill($request->all())`, `forceFill($request->all())`; Symfony forms/serializers that bind every property (`allow_extra_fields`, `#[Groups]` missing). Use `validated()` or `only([...])`. CWE-915.
- **Type juggling:** `==` or `!=` where `===` is needed on password hashes, tokens, MACs, signatures or API keys (`"0e123" == "0e456"` is true; `0 == "admin"` is true in PHP 7), `in_array($v, $list)` and `array_search` without `strict`, `switch` on strings from input, `strcmp()` return compared loosely (an array input returns `null`), `md5(...) == ...`, `hash_equals` skipped. CWE-697, CWE-208.
- **Weak randomness:** `rand()`, `mt_rand()`, `uniqid()`, `lcg_value`, `shuffle`/`array_rand`, `str_shuffle`, `time()`-based or `md5(time())` values for session ids, reset tokens, API keys or OTPs, instead of `random_bytes`/`random_int` (or Laravel `Str::random`). CWE-338, CWE-330.
- **Password storage:** `md5`, `sha1`, `hash('sha256', ...)` or `crypt` with a weak salt for passwords instead of `password_hash(..., PASSWORD_DEFAULT)` and `password_verify`; Laravel `Hash::make` replaced with a custom hasher; passwords compared in SQL. CWE-916, CWE-327.
- **Sessions and cookies:** `session_start()` with no `session.cookie_secure`, `cookie_httponly`, `cookie_samesite`; `session_regenerate_id(true)` not called at login; session ids accepted from `$_GET` (`use_trans_sid`); Laravel `SESSION_SECURE_COOKIE=false`, `http_only` false; hard-coded `APP_KEY` in the repo (it signs and encrypts cookies, and in old Laravel versions an exposed key leads to remote code execution through unserialize). CWE-614, CWE-1004, CWE-384, CWE-798.
- **CSRF:** Laravel `VerifyCsrfToken::$except` listing wide patterns (`'*'`, `api/*` with cookie auth), `@csrf` missing in Blade forms, Symfony `csrf_protection: false`, plain PHP forms with no token, state changes on GET routes. CWE-352.

## Configuration and logging
- **Debug mode:** `APP_DEBUG=true` or `'debug' => true` in production config (Laravel's Ignition page shows environment values and, in some versions, allows code execution), `APP_ENV=local`, Symfony `APP_ENV=dev` with the profiler (`/_profiler`, `/_wdt`) exposed, `ini_set('display_errors', 1)`, Laravel Telescope, Horizon or Debugbar reachable without a gate. CWE-489, CWE-209, CWE-215.
- **Secrets and `.env`:** a committed `.env` (with `APP_KEY`, `DB_PASSWORD`, mail and AWS keys), credentials in `config/*.php` defaults (`env('DB_PASSWORD', 'secret')`), `phpinfo()` or `env()` output logged. CWE-798, CWE-540.
- **TLS and CORS:** `CURLOPT_SSL_VERIFYPEER => false`, `CURLOPT_SSL_VERIFYHOST => 0`, Guzzle `'verify' => false`; `fruitcake/laravel-cors` / Laravel `config/cors.php` with `allowed_origins => ['*']` and `supports_credentials => true`, or `Access-Control-Allow-Origin` echoed from `$_SERVER['HTTP_ORIGIN']`. CWE-295, CWE-942.
- **Logging:** `Log::info($request->all())`, `error_log(print_r($_POST, true))`, `Log::debug('login', ['password' => ...])`, query logging with bindings (`DB::listen`) holding personal data, `dd()`/`dump()`/`var_dump()` left in code. CWE-532.
- **Dependencies and PHP version:** `composer.lock` not committed, packages with advisories (check with `composer audit`), end-of-life PHP versions in `composer.json` `require` or the Dockerfile, and `php.ini` flags such as `allow_url_include`, `expose_php` or `open_basedir` left unset. CWE-1104.
